# Les captures de la page de présentation

Déposez ici les captures d'écran de groma, au nom exact ci-dessous. Elles sont publiques : utilisez les données fictives, jamais de vraies personnes. Chaque vue existe en deux formats : l'ordinateur (PNG, 1 600 px de large) et le téléphone, au même nom suivi de `-mobile` (PNG, 390 × 844, par exemple `02-fiche-mobile.png`). Le téléphone se pose sur le coin de la vue d'ordinateur.

| Fichier | Ce qu'il montre |
| --- | --- |
| `01-liste.png` | la liste des chantiers (onglet « À traiter » ou tous) |
| `02-fiche.png` | la fiche d'un chantier en cours : étapes, ce qui bloque, lots |
| `03-fil.png` | le fil en onglets, avec un « Qui voit ça ? » |
| `04-documents.png` | l'onglet Documents avec les pièces attendues |
| `05-pv.png` | un PV de réception signé (la carte Réception ou le PDF) |
| `06-courrier.png` | la fiche d'un courrier lu par l'IA, avec son bilan |
| `07-questions.png` | une réponse sur les documents, avec ses citations |
| `08-assistant.png` | l'assistant et sa réponse, ou la file « À valider » |
| `09-nuit.png` | la machine de nuit : exécutions, coût, ce que la nuit dit |

Tant qu'un fichier manque, sa place reste en noir avec son nom : la page ne bouge pas. Après dépôt, un envoi sur GitHub la met à jour.
